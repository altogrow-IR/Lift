# LIFT — 自分のためのトレーニングノート

トレーニング中の記録を、少ない操作で済ませる個人用Webアプリです。React / TypeScript / Viteで構築し、ログイン・APIキー・サーバーは不要です。

## 使い方

1. 「記録」で種目を選ぶ。
2. 重量・回数を ± ボタンか直接入力で調整し、「1セット記録する」を押す。
3. 次のセットでは数値をそのまま使う。種目を選び直すと、その種目の最新の数値を読み込む。
4. 「成長」で種目ごとのグラフ、「履歴」で過去の記録を確認する。

- ウエイト（kg・回数）／自重（回数）／時間（秒）の種目に対応。種目一覧から自分の種目を追加できます。
- 日付を変更すると過去の日にも記録できます。初期重量20kg・回数10回・時間30秒は入力用の初期値で、トレーニングの推奨値ではありません。
- 同じ日に何セットでも追加可能。各記録をタップすると編集・削除できます。直近の記録・変更・削除は通知の「元に戻す」で10秒間取り消せます。
- 休憩時間はOFF／60／90／120／180秒。今日のセットを記録すると開始し、リロード後も同じタブなら残り時間を復元します。音は鳴りません。
- グラフ：1日ごとの最高重量、または重量×回数の合計（総負荷）。自重は最多回数、時間種目は最長時間。表示期間は直近30日／90日／すべて。スライダー・数値一覧でも日ごとの値を確認できます。
- サンプルグラフは「設定」から表示できます。実データへ混ぜたり保存したりしません。

## 起動

Node.js 22.12以上、または24系を使用してください。

```sh
npm ci
npm run dev
```

表示されるURLをブラウザで開きます。本番版のローカル確認：

```sh
npm run build
npm run preview -- --port 4173
```

Windowsの制限された実行環境でViteの開発サーバーが親フォルダへのアクセスエラーを出す場合は、通常のターミナルで実行するか、ビルド済みの `npm run preview` を使用してください。

## 記録とバックアップ

- localStorageキー `lift.training.v1`、バージョン付きJSONで保存。種目IDは変更しない固定IDです。
- 記録はブラウザ・端末・アクセスURLごとに別々です。クラウド同期はありません。localhostで記録した内容も公開URLへ自動移行されません。
- 「設定 → バックアップを保存」でJSONをダウンロードし、同じ画面から復元できます。復元は現在の記録を置き換えるため、内容の確認後に実行します。
- 保存失敗時は成功表示を出さず、入力値を保持します。壊れたデータや未知の保存バージョンは上書きせず、元データの救出・復元画面を案内します。
- プライベートブラウズやブラウザのデータ削除によって記録が消える可能性があります。定期的なバックアップを推奨します。
- 複数タブではstorageイベントで更新を反映し、保存直前にも保存済みデータを読み直します。厳密な同時書き込みロックはありません。

## 検証

```sh
npm run typecheck
npm test
npm run build
```

ブラウザテストは別のターミナルでプレビューを起動してから実行します。Windowsではインストール済みのMicrosoft Edgeを使います。

```sh
npm run preview -- --port 4173 --strictPort
npm run test:browser
```

他の環境ではChromiumをインストールし、環境変数 `PLAYWRIGHT_CHANNEL=chromium` を設定してください。テストするURLは `TEST_URL` で変更できます。

```sh
npx playwright install chromium
```

ブラウザテストは独立したブラウザコンテキストで実行するため、利用中のブラウザの記録は変更しません。320／375／390／430／768／1024／1440px、保存・編集・Undo・種目追加・集計・バックアップ・破損・保存失敗・休憩・別タブ同期を確認します。実機のSafari／Androidやバックグラウンド中の通知は別途確認が必要です。

## GitHub Pages

`base: './'`、画面切り替えはReactの状態で管理し、URLルーティングを使用しません。リポジトリ名配下で開いてもアセットを相対パスで読み込みます。

`.github/workflows/pages.yml` を用意しています。GitHubリポジトリへpushし、Settings → Pages → Build and deploymentのSourceを **GitHub Actions** に設定すると、main／masterへのpushまたは手動実行でテスト・ビルド・公開できます。

リポジトリ：[altogrow-IR/Lift](https://github.com/altogrow-IR/Lift)

公開URL：[LIFT](https://altogrow-ir.github.io/Lift/)

ローカル版の記録を公開版で使う場合は、ローカル版の「設定」でバックアップを保存し、公開版で復元してください。

参考：[Vite公式ガイド](https://vite.dev/guide/) / [GitHub Pages公式ドキュメント](https://docs.github.com/en/pages)

## 記録・種目管理・比較表示

- 入力途中の数値は種目・記録日ごとに保持します。同じタブの再読み込みでも復元します。入力途中の値は実記録やバックアップには含めません。復元・初期化で入力途中の値を消去します。
- 「設定 → 種目を整理」で名前の変更・非表示・再表示ができます。種目IDと履歴は保ち、非表示の種目も成長・履歴から確認できます。少なくとも1種目は表示します。
- 成長画面の前回比は最新の記録日と直前の記録日の差。自己ベストは表示期間にかかわらず全期間の最大値です。総負荷では日ごとの総負荷を比較します。
- 前回の全セットは今日の記録があればその前の記録日、なければ最新の記録日を表示します。成長画面から選択中の種目で記録を開始できます。
